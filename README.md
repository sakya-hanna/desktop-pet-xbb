# 小伯白桌宠 · desktop-pet-xbb

Windows 桌宠工程：Electron + WebGL2 二维立绘网格，角色为《玉响未来》的小伯白。

本仓库公开管理代码、测试和脱敏文档。角色图片、PSD、原始游戏素材、模型文件、运行数据与密钥不上传，因此单独克隆本仓库不能直接显示完整桌宠。

## 当前基线

`main` 首次导入的是本地已确认的第20批正式工程代码，不是把所有历史候选混在一起：

- 二维立绘网格、外侧长发及三束前发驱动，表情与眨眼。
- 待机、跳跃、触摸反馈、气泡、工具条拖动与轮廓穿透。
- Ctrl+滚轮缩放、窗口偏好保存。
- 独立聊天与模型设置窗口；OpenAI兼容接口由用户自行配置。
- 不启用鼠标视线跟随；文字聊天不驱动口型，语音未接入。

第23批双手静态美术仍属本地待审候选。第24批聊天主题改造独立开发，未经确认不混入本基线。详见 [开发约定](docs/development.md)。

## 目录

- `puppet/`：Electron主进程、沙箱preload、聊天/设置/气泡窗口。
- `puppet/rig/`：当前2D网格入口和渲染/交互代码。
- `tests/`：Node回归、手动隔离Electron验证与本地图像测试。
- `tools/`：素材构建/验证源代码与Node测试入口。
- `docs/`：运行前提、素材边界和开发约定。

保留的 `puppet/index.html`、`index2.html` 等是历史页面；当前正式入口是 `puppet/rig/index.html`，不是Live2D。未导入旧Live2D目录、供应商压缩库、模型与历史交付批次。

## 运行Node测试

需要本机Node.js。在仓库根目录执行：

    node tools/test.cjs

该入口逐文件运行 `tests/*.test.js`，使用独立临时目录，不启动桌宠，不读取真实聊天/模型设置，不请求外网模型。`ai-client.test.js` 会建立127.0.0.1回环HTTP服务，因此不是严格的“零网络”测试。渲染harness使用模拟图像/WebGL，不需要私有角色图片；通过不等于实际GPU或视觉验收。

Python素材测试需要自行提供本地素材以及Pillow/numpy；不包含在上述命令中。不要批量执行 `tests/*.cjs`，这些是不同用途的Electron验证脚本，部分需要专门的隔离启动条件。

## 本地运行前提

1. 自行准备有权使用的角色贴图，按 [本地素材说明](docs/local-assets.md) 放入对应路径。不要将这些文件强制加入Git。
2. 自行安装/准备Electron。本仓库不携带Electron二进制，也不会自动下载依赖。
3. 原Windows入口 `puppet/run-rig.bat` 使用 `%USERPROFILE%\.dsh\electron\electron.exe`。若该路径不存在，使用自己的Electron可执行文件，并令 `PUPPET_PAGE=rig/index.html` 后启动 `puppet/main.js`。

注意：正常启动会读取/保存本机Electron用户数据。新克隆目录不是数据沙盒，不能当成隔离测试入口。模型设置与聊天记录不应放到仓库中。
