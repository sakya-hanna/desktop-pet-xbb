# 本地素材（不纳入公开仓库）

本仓库仅管理源代码。PNG、PSD、Live2D模型、原始游戏图片、视频和历史美术候选均留在本地；`.gitignore` 是防误提交措施，不是保密系统，仍需检查实际暂存列表。

## 当前2D入口

将已有且有权使用的运行贴图放入 `puppet/rig/assets/`，保持原相对路径和文件名。所需名称、画布尺寸与采样参数由以下源文件引用：

- `puppet/rig/js/assets.js`：身体与表情。
- `puppet/rig/js/blink-assets.js`：眨眼贴图。
- `puppet/rig/js/hair-assets.js`：外侧发束、底图。
- `puppet/rig/js/front-hair-assets.js`：三束前发及接影相关贴图。

不要只复制一张完整立绘就认为所有分层/表情已具备。缺少前发资源时有回退逻辑，但基础身体与表情图片仍须自行提供；本仓库没有用空白图片伪造素材齐全。

第24批聊天主题候选需要本地头像 `puppet/assets/chat/baijie-avatar.png`，该PNG同样不上传。基线旧聊天页不依赖它。

## 不在本次导入中的内容

- 角色原画、Photoshop源文件和候选图片。
- 旧Live2D模型、编辑工程、供应商压缩库。
- 原项目运行缓存、各批截图/报告/备份。
- 用户的模型设置、聊天、加密状态。

Node逻辑测试使用模拟图像；Python像素/素材回归和真实Electron截图必须在本地补齐资源后单独进行。不要为了让公开仓库“开箱即跑”上传未明确授权分发的素材。
