# 开发与发布约定

## 分支

- `main`：已确认正式代码基线；首次导入来自第20批正式工程。
- `feat/chat-theme`：第24批头像/竖屏气泡/白姐主题候选，完成代码与隔离测试后再提交。
- 其他功能以 `feat/`、修复以 `fix/`、文档以 `docs/` 建分支。

候选实现、自动测试通过、用户视觉验收和正式部署是不同状态。推送到GitHub或合并分支不会自动替换本机正在运行的桌宠；未经确认不移动、覆盖原正式工程，也不自动重启。

## 修改前后

1. 确认当前分支和工作区，避免覆盖未提交改动。
2. 功能改动先补测试，再做最小实现；保留原有消息文本安全、输入法、取消与草稿行为。
3. 运行 `node tools/test.cjs`。Electron/GPU和素材测试另行授权、隔离并记录。
4. 提交前检查 `git diff --cached` 及 `git diff --cached --name-only`，不使用强制添加绕过素材/凭据忽略规则。
5. 用清晰的 `feat:`、`fix:`、`docs:`、`chore:` 提交说明。推送后核对远端分支提交SHA。

当前未配置GitHub Actions；本地测试结果不应写成远端CI通过。没有因首次导入而改写历史候选、删除原素材或变更仓库可见性。

## 隔离与隐私

不提交聊天、模型设置、API Key、密文、Local State、用户目录、运行profile、截图日志或PS源文件。测试凭据只可使用明确无效的fixture。

隐藏Electron验证必须另行隔离userData/sessionData/日志，使用测试服务，禁止读真实密钥或请求模型；复制源码或设置PUPPET_STATELESS不等于完整隔离。

`tools/build_rig_assets.py` 是含旧工作目录的历史烘焙工具，不是日常启动步骤。构建素材前先审查输入、输出与覆盖范围；不要直接执行历史构建脚本重生成已确认素材。
